Emberline is a round-based tactical FPS in the browser: Ember attackers plant a charge at site A or B in the Foundry Yard while Warden defenders hold the lanes, with a buy menu, economy, recoil and spread that reward stopping to aim, and nine bots that patrol, hold angles, and react to what they see and hear.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome and click to play. No build step, no network requests: three.js 0.187.0 is vendored under game/vendor/three/.
